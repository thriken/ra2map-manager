[红警2地图管理器GUI]

功能说明：
1. 将地图整理放置在 maps 文件夹，支持子文件夹分类
2. config.ini 保存多版本游戏目录
3. 地图库按文件夹层级展示，支持将选中的地图安装到指定的游戏目录（可多选、可整文件夹安装）
4. 支持列出和移除游戏目录中的第三方地图
5. 自动读取地图文件内的真实名称（[Basic] Name=），读取失败时回退显示文件名
6. 安装时按地图格式自动匹配游戏版本，不兼容的格式自动跳过
7. 一键启动游戏（原版 ra2.exe，尤里复仇 ra2md.exe / yuri.exe）

地图格式说明：
- .map  任务地图：原版《红色警戒2》与《尤里的复仇》通用，仅用于单人战役，不能作为遭遇战对战地图
- .mpr  原版遭遇战地图：仅适用于原版红警2（含共和国之辉等主流MOD），尤里的复仇原生不识别
- .yrm  尤里遭遇战地图：仅适配《尤里的复仇》本体及衍生MOD，原版红警2无法识别
- .mmx  多地图包（MultiMap）：内含多个遭遇战地图，原版与尤里复仇通用

安装自动匹配规则：
- .mpr 只安装到“原版/MOD”目录，.yrm 只安装到“尤里复仇/MOD”目录
- .map 与 .mmx 两个版本均可安装

文件说明：
- MapManagerGUI.py   图形界面版（PyQt6/PyQt5 双兼容，自动选择）
- config.ini         游戏版本配置（见下方格式）
- maps/              地图库文件夹
- 打包版（dist\RA2MapManager.exe）：首次运行会自动在 exe 同目录
  生成默认 config.ini 与 maps 文件夹，无需手工创建

config.ini 格式示例（可自行增删版本）：
[ra2]
name=红色警戒2原版
gamedir=

[ra2md]
name=红色警戒2：尤里的复仇
gamedir=

[ra2glory]
name=红色警戒2共和国之辉
gamedir=

游戏目录识别规则：
- 目录中存在 gamemd.exe 或 yuri.dll  -> 识别为“尤里复仇/MOD”
- 否则                                -> 识别为“原版/MOD”

启动游戏规则：
- 原版（ra2）：ra2.exe（备选 game.exe）
- 尤里复仇/MOD（yr）：ra2md.exe / yuri.exe（MOD 备选 gamemd.exe）

使用提示：
- 双击游戏版本表格中的目录列，可直接选择游戏根目录
- 点击“▶ 启动游戏”按钮启动当前选中的游戏版本
- 地图分发默认平铺到游戏根目录（原版红警不识别子目录地图）
- 若游戏安装在 Program Files 等系统保护目录（普通权限无法写入，
  会导致安装/移除地图失败或启动 ra2.exe 权限不足），启动程序或
  点击“▶ 启动游戏”时会询问是否以管理员身份运行；仅此时询问，
  平时不弹窗；Windows XP 无 UAC，不受影响

运行环境：
- Windows 7 及以上：Python 3.x + PyQt6 或 PyQt5（源码直接运行）
- Windows XP：源码运行需 32位 Python 3.5.4 + PyQt5 5.9.2；
  打包使用 build_xp.bat（PyInstaller 3.3.1 加 --noupx），
  产物 dist\RA2MapManager.exe（32位）可直接在 XP 运行


[说明]
.map 格式‌：是《红色警戒2》原版、《尤里的复仇》通用的任务地图格式，仅用于单人游戏的新战役模式，无法直接作为遭遇战对战地图使用。
‌.mpr 格式‌：是《红色警戒2》原版（含共和国之辉等主流MOD）的专属遭遇战地图格式，仅能在原版红警2环境下加载运行，尤里的复仇原生不识别该格式作为对战地图。
‌.yrm 格式‌：是资料片《尤里的复仇》的专属遭遇战地图格式，仅适配尤里的复仇本体及对应衍生MOD，原版红警2无法识别该类地图文件。
