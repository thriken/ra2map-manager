========================================
红警2多版本地图管理器 —— Windows XP 打包说明
========================================

一、为什么是这套组合
----------------------------------------
本程序有两个入口，核心逻辑共用 map_utils.py：
  - MapManagerGUI.py（PyQt6/PyQt5，Win7 及以上，界面现代）
  - MapManagerTk.py（Tkinter，XP 专用，经典界面）

PyQt6 有两个硬性障碍，与 32/64 位无关：
  1. Qt6 官方已取消 Windows 32 位版本（无法 32 位打包）
  2. Qt6 最低要求 Windows 10，XP/Win7/Win8 一律无法运行

XP 版因此使用纯标准库技术栈，零第三方依赖：
  - Python 3.4.4  32 位   （3.5 起官方放弃 Windows XP，
                           3.4.4 是最后一个支持 XP 的版本）
  - Tkinter               （Python 自带，无需安装 PyQt5）
  - PyInstaller 3.3.1     （支持 Python 3.3~3.6，含 3.4）

注意：Python 3.5 及以上官方不支持 XP。用 3.5/3.6 打包出的 exe
内含 python35.dll 等运行库，XP 上无法加载运行，必须用 32 位
Python 3.4.4 打包，换机器运行并不能绕过。

二、打包步骤
----------------------------------------
1. 在打包机（任意现代 Windows）安装 32 位 Python 3.4.4：
      https://www.python.org/ftp/python/3.4.4/python-3.4.4.exe
   安装时勾选：
     - "py launcher"
     - "Add python.exe to PATH"
   （也可不勾选，之后设置环境变量 PYXP34 指向安装目录，如
    PYXP34=C:\Python34-32）

2. 双击运行项目根目录下的 build_xp.bat
   脚本会自动：
     - 定位 32 位 Python 3.4（优先 PYXP34，其次 py -3.4-32）
     - 安装 pyinstaller==3.3.1（Tk 为 Python 标准库，无需装 GUI 库）
     - 执行打包，产物输出到 dist\RA2MapManagerXP.exe

3. 将 dist\RA2MapManagerXP.exe 拷贝到 XP 机器。

（若此前用 3.5 打包过，dist 里那份 exe 无法在 XP 运行，需按本
 步骤用 3.4 重新打包；用 3.4 打包后产物为 32 位 PE。）

三、在 XP 机器上运行
----------------------------------------
1. Tk 版无 Qt/VC 运行库依赖，PyInstaller 打包时通常已把
   msvcr100.dll 一并内置；若 XP 上仍提示缺该 DLL，安装
   VC++ 2010 运行库（32 位）：
      https://www.microsoft.com/en-us/download/details.aspx?id=5555

2. 程序为单文件版（--onefile），首次启动需解压到临时目录，XP 上
   可能稍慢，属正常现象。

3. 首次运行会自动在 exe 同目录生成默认 config.ini（游戏版本配置）
   和 maps 文件夹，无需手工创建；之后直接编辑 exe 旁的 config.ini
   即可增删游戏版本。

4. 游戏目录识别、地图安装等逻辑与新版一致，无需额外配置。

5. Windows 7 及以上新增"检测到不可写的游戏目录时询问是否以管理员
   身份运行"功能（依赖 UAC）。Windows XP 没有 UAC 机制，该询问
   不会触发，行为与旧版完全一致。

四、常见问题
----------------------------------------
Q: 杀毒软件提示 exe 有风险？
A: PyInstaller 单文件包常被误报。可改用目录版打包绕开：
      py -3.4-32 -m PyInstaller --onedir --windowed --clean --name RA2MapManagerXP MapManagerTk.py
   然后压缩 dist\RA2MapManagerXP\ 整个文件夹分发。

Q: 能用 Python 3.5 吗（本机装的就是 3.5）？
A: 不能用于 XP。Python 3.5 起官方放弃 Windows XP，3.5 打包的
   exe 在 XP 上无法运行。必须用 32 位 Python 3.4.4 打包，
   GUI 用 Python 自带的 Tkinter。

Q: 为什么不用 PyQt5 5.6.2 打 XP 版？
A: PyQt5 5.6.2 的 cp34 wheel 已从主流镜像下架，获取困难；且
   Qt 运行时体积大。Tkinter 是 Python 标准库，零依赖、体积小，
   功能已覆盖本工具全部需求，更适合 XP 小机器。

Q: 打包机本身就是 XP 吗？
A: 不需要。在任意机器打好包，拷贝到 XP 运行即可。

Q: 打包出的 exe 运行时崩溃？
A: 不要使用 UPX 压缩（build_xp.bat 已固定使用 --noupx）。

Q: Tk 版和 PyQt 版有什么区别？
A: 功能一致。MapManagerTk.py 只依赖标准库，经典界面，按
   1024x600 小屏优化；MapManagerGUI.py 使用 PyQt6/PyQt5，
   界面更现代。两个入口共用 map_utils.py 全部逻辑。
